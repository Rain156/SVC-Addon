# 资源来源与许可

当前版本没有引入第三方纹理、模型、音频、字体或图标，也未从 Simple Voice Chat 复制资源。中英文语言文件为项目原创，适用仓库 MIT 许可。

后续可选用 MIT、BSD、Apache-2.0、CC0 等允许目标用途的资源。许可证必须覆盖具体资源本身；代码仓库使用 MIT 不等于所有美术自动采用 MIT。

每次引入时在下表登记，并将要求保留的许可正文放在资源同目录或 `licenses/`；同时记录模型、纹理和音频是否有不同许可证。CC-BY 资源额外满足署名要求后方可使用。游戏自带资源通过游戏资源标识引用，不复制到仓库。
